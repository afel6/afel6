### Featured: [section-team](https://github.com/afel6/section-team)
A Claude Code plugin that turns a session into a supervised team of AI agents, where every piece of code must pass a strict review before it is done.

**8.6/10 vs 7.1 for plain Claude Code · 12 of 12 blind judge votes · every hidden test passed**

I ran the 17-round benchmark myself and the judges are AI models; the hidden tests are the objective part. [Method and results](https://github.com/afel6/section-team/blob/main/docs/benchmark-2026-10-24.md).

### Open source: [NALTRA](https://github.com/Rxd3/NALTRA)
A multilingual NLP benchmark that classifies 31,407 EU research projects (English and Turkish) into a 586-node science taxonomy. I'm the top contributor: I built the dataset release, the model ensembles, the evaluation pipeline (robustness, out-of-scope rejection, calibration, latency), the results dashboard and the tests.

### What I build
- **AI agents and multi-agent systems:** supervisor-and-specialist teams, tool use, agent-to-agent delegation and safe database queries.
- **RAG and knowledge assistants:** chat over documents, manuals and standards with cited answers, in the cloud or fully offline.
- **Private, on-premise AI:** local models and search, audit logs, data that never leaves the building.
- **Full-stack web apps and dashboards:** React frontends, FastAPI and Node backends, PostgreSQL and Supabase, live charts and maps.
- **Arabic and offline-first apps:** right-to-left interfaces and apps that keep working without a connection, such as offline QR workflows.
- **Business and quality systems:** document control, review and approval workflows, compliance tracking and corrective actions (CAPA).
- **Data extraction and automatic reports:** messy Excel, PDF and Word files turned into clean data; Word, Excel, PowerPoint and PDF reports generated automatically.
- **Engineering and scientific software:** physics models checked automatically, curve fitting and simulation, including oil and gas.
- **AI coding tools:** Claude Code plugins and agent teams that write, test and review code.
- **Quality and security built in:** automated tests from unit to end-to-end, CI/CD, Docker and security hardening.
