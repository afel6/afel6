### 🚀 What I can build
- **AI agents and multi-agent systems.** Teams of agents with a supervisor and specialists, agents that use tools, delegate to each other, and query databases safely.
- **RAG and knowledge assistants.** Chat over your documents, manuals and standards, with answers that cite their sources. In the cloud (Claude, Gemini) or fully offline with local models.
- **Private, offline AI.** On-premise and air-gapped systems where data never leaves the building: local models, local search, audit logs of every result.
- **Engineering and scientific software.** Physics models and calculations in code, checked automatically against physical laws: curve fitting, simulation, data validation.
- **Petroleum engineering tools.** Reservoir fluids (PVT), core analysis (SCAL), equations of state, well design, nodal analysis, multiphase flow, artificial lift, and exports for reservoir simulators.
- **Data extraction and automatic reports.** Turn messy Excel, PDF and Word files into clean data, and generate Word, Excel, PowerPoint and PDF reports automatically.
- **Full-stack web apps and dashboards.** React frontends, FastAPI and Node backends, PostgreSQL, live charts and maps, Arabic (right-to-left) interfaces, offline-first and QR features.
- **Business and quality systems.** Document control, review and approval workflows, compliance tracking and corrective actions (CAPA).
- **AI coding tools.** Claude Code plugins and AI agent teams that write, test and review code.
- **Quality and security built in.** Automated tests from unit to end-to-end, CI/CD, Docker, security hardening and secret scanning.

### ⭐ Featured: [section-team](https://github.com/afel6/section-team)
A Claude Code plugin that turns a session into a supervised team of AI agents, where every piece of code must pass a strict review before it is done. In blind benchmarks it scored **8.6/10 against 7.1** for plain Claude Code and won **12 of 12** judge votes.
